KITA-LOG
A Web-Based Sales and Expense Tracking System for Small Businesses

---

## PROJECT DESCRIPTION

KITA-LOG is a simple web-based financial tracking system developed for small business owners. The system allows users to record daily sales, track expenses, and automatically calculate profit summaries.

The goal of the system is to help small businesses monitor their finances more efficiently and make better financial decisions.

---

## SYSTEM FEATURES

• Record daily sales
• Track and categorize expenses
• Automatic profit calculation
• Financial summaries and reports
• Simple dashboard overview

## INSTALLATION GUIDE

1. Install XAMPP (or any PHP server environment)

2. Place the project folder inside the htdocs directory

Example:
xampp/htdocs/kita-log/

3. Start the following services in XAMPP:

* Apache
* MySQL

4. Create the database

Open phpMyAdmin and create a new database named:

kitalog_db

5. Import the database file

Import the provided SQL file into the database.

6. Run the system

Open your browser and go to:

http://localhost/kita-log
